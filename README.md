# HTML_CSS
Kursövningar för Yrkeshögskola (YH) - HTML och CSS

## Innehåll

Detta repository innehåller 5 progressiva övningar som täcker grunderna i HTML och CSS för YH-studenter.

### Övning 1: Grundläggande HTML-struktur
📁 `ovning1-grundlaggande-html/`

Lär dig grundläggande HTML-struktur och semantiska element. Övningen täcker:
- Korrekt HTML5-dokumentstruktur
- Semantiska element (header, nav, main, article, footer)
- Rubriker, listor, bilder och länkar
- Tillgänglighet med alt-text

### Övning 2: CSS-grunder och Styling
📁 `ovning2-css-grunder/`

Introduktion till CSS-styling och box-modellen. Övningen täcker:
- Externa CSS-filer
- Selektorer (element, klass, ID)
- Färger, typsnitt och spacing
- Box-modellen (margin, padding, border)
- Hover-effekter och CSS-variabler

### Övning 3: CSS Flexbox Layout
📁 `ovning3-flexbox/`

Lär dig skapa flexibla layouts med Flexbox. Övningen täcker:
- Flexbox-egenskaper
- Responsiv navigationbar
- Kortlayouter med flex
- Bildgallerier
- Justify-content och align-items

### Övning 4: CSS Grid Layout
📁 `ovning4-grid/`

Avancerade layouts med CSS Grid. Övningen täcker:
- Grid-template-columns och rows
- Grid-template-areas
- Dashboard-layouts
- Fotogallerier med grid
- Responsiva grid-layouts

### Övning 5: Responsiv Design och Media Queries
📁 `ovning5-responsiv-design/`

Skapa fullständigt responsiva webbsidor. Övningen täcker:
- Mobile-first approach
- Media queries för olika enheter
- Hamburger-meny
- Breakpoints (mobil, tablet, desktop)
- Tillgänglighet och touch targets

## Kom igång

Varje övning är självständig och innehåller:
- `README.md` - Instruktioner och krav för övningen
- `index.html` - Exempel-HTML-fil
- `style.css` - CSS-stylesheet
- `script.js` - JavaScript (där relevant)

### Så här använder du övningarna:

1. Börja med övning 1 och arbeta dig framåt progressivt
2. Läs README.md i varje övning för att förstå kraven
3. Öppna index.html i din webbläsare för att se exemplet
4. Studera koden och experimentera med egna ändringar
5. Försök implementera bonusutmaningarna

## Rekommenderade verktyg

- **Code Editor**: VS Code, Sublime Text eller liknande
- **Webbläsare**: Chrome eller Firefox med Developer Tools
- **Validering**: W3C HTML Validator och CSS Validator
- **Extensions**: Live Server för VS Code (för lokal utveckling)

## Tips för lärande

- Börja alltid med att förstå grundstrukturen
- Experimentera med koden - ändra värden och se vad som händer
- Använd browser DevTools för att inspektera element
- Validera din kod regelbundet
- Testa på olika skärmstorlekar
- Bygg egna varianter av övningarna
