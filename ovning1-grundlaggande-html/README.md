# Övning 1: Grundläggande HTML-struktur

## Mål
Att lära sig grundläggande HTML-struktur och semantiska element.

## Uppgift
Skapa en enkel webbsida om dig själv eller ett ämne du är intresserad av.

## Krav
- Använd korrekt HTML5-dokumentstruktur med `<!DOCTYPE html>`
- Inkludera `<head>` med title och meta-taggar
- Använd semantiska HTML5-element:
  - `<header>` för sidans huvud
  - `<nav>` för navigation
  - `<main>` för huvudinnehåll
  - `<article>` för artikelinnehåll
  - `<footer>` för sidfot
- Inkludera minst:
  - 3 olika rubriknivåer (h1, h2, h3)
  - 2 stycken text
  - En numrerad lista (ol)
  - En punktlista (ul)
  - En bild med alt-text
  - En länk till en extern webbplats

## Bonusutmaning
- Lägg till en `<aside>` med relaterad information
- Använd `<figure>` och `<figcaption>` för din bild
- Lägg till en tabell med information

## Tips
- Validera din HTML med W3C Validator
- Tänk på att använda rätt element för rätt syfte (semantik)
- Glöm inte alt-text på bilder för tillgänglighet
