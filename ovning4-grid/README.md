# Övning 4: CSS Grid Layout

## Mål
Att lära sig CSS Grid för att skapa avancerade och responsiva grid-layouts.

## Uppgift
Skapa en responsiv webbsida med CSS Grid för olika layouter.

## Krav
- Skapa en huvudlayout med CSS Grid (header, sidebar, main, footer)
- Bygg ett fotogalleri eller produktgalleri med Grid
- Använd grid-egenskaper:
  - `display: grid`
  - `grid-template-columns`
  - `grid-template-rows`
  - `grid-template-areas`
  - `gap`
  - `grid-column` / `grid-row` för spanning
- Skapa minst 2 olika grid-layouts

## Bonusutmaning
- Skapa en dashboard-layout med olika storleksområden
- Använd `auto-fit` eller `auto-fill` med `minmax()`
- Implementera nested grids (grids inom grids)
- Gör layouten responsiv med media queries som ändrar grid-strukturen

## Tips
- Använd Firefox Grid Inspector för att visualisera grid
- Testa `grid-template-areas` för semantiska layouts
- Kombinera Grid och Flexbox för bästa resultat
- Tänk mobile-first och anpassa grid för olika skärmstorlekar
