# Övning 3: CSS Flexbox Layout

## Mål
Att lära sig CSS Flexbox för att skapa flexibla och responsiva layouts.

## Uppgift
Skapa en responsiv webbsida med olika flexbox-layouts.

## Krav
- Skapa en responsiv navigationsbar med flexbox
- Bygg en kort-layout med flexbox
- Använd flexbox-egenskaper:
  - `display: flex`
  - `flex-direction`
  - `justify-content`
  - `align-items`
  - `flex-wrap`
  - `gap`
- Skapa minst 3 olika sektioner som använder flexbox

## Bonusutmaning
- Skapa en "hero section" med centrerat innehåll
- Bygg en footer med flera kolumner
- Använd `flex-grow`, `flex-shrink` och `flex-basis`
- Gör layouten helt responsiv med flex-wrap

## Tips
- Använd Chrome DevTools för att experimentera med flexbox-värden
- Testa olika kombinationer av justify-content och align-items
- Tänk på både huvudaxeln och korsaxeln
- Använd gap istället för margins mellan flex-items
