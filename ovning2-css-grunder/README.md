# Övning 2: CSS-grunder och Styling

## Mål
Att lära sig grundläggande CSS-styling och box-modellen.

## Uppgift
Styla en webbsida med hjälp av extern CSS.

## Krav
- Skapa en HTML-fil och länka till en extern CSS-fil
- Använd olika typer av selektorer:
  - Element-selektorer (t.ex. `p`, `h1`)
  - Klass-selektorer (t.ex. `.klass`)
  - ID-selektorer (t.ex. `#id`)
- Styla följande:
  - Bakgrundsfärger
  - Textfärger och typsnitt
  - Margins och padding
  - Borders och border-radius
  - Text-alignment
- Visa förståelse för box-modellen (content, padding, border, margin)

## Bonusutmaning
- Använd Google Fonts för ett anpassat typsnitt
- Skapa hover-effekter på länkar och knappar
- Använd CSS-variabler för färger
- Lägg till box-shadow för djup

## Tips
- Använd Chrome DevTools för att inspektera och testa CSS
- Tänk på kontrast mellan text och bakgrund
- Var konsekvent med spacing (margins och padding)
