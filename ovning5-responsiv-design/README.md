# Övning 5: Responsiv Design och Media Queries

## Mål
Att lära sig skapa responsiva webbsidor som fungerar på alla enheter.

## Uppgift
Skapa en helt responsiv webbsida med mobile-first approach.

## Krav
- Använd mobile-first design (börja med mobil, bygg upp till desktop)
- Implementera media queries för minst 3 breakpoints:
  - Mobil (< 768px)
  - Tablet (768px - 1024px)
  - Desktop (> 1024px)
- Skapa en responsiv navigationsbar:
  - Hamburger-meny på mobil
  - Full meny på desktop
- Använd responsiva bilder och viewport-meta tag
- Implementera flexibel typografi (rem/em units)

## Bonusutmaning
- Lägg till smooth transitions mellan breakpoints
- Använd CSS clamp() för fluid typography
- Implementera touch-friendly buttons på mobil (minst 44x44px)
- Testa med Chrome DevTools Device Mode
- Lägg till en "skip to content" länk för tillgänglighet

## Tips
- Testa på riktiga enheter, inte bara i DevTools
- Använd relativa units (%, rem, em) istället för px
- Tänk på touch targets på mobila enheter
- Överväg landscape vs portrait orientering
- Använd CSS Grid och Flexbox för responsiva layouts
